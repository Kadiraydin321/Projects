Google Drive API Kurulum Kılavuzu

Google Drive entegrasyonunu kullanabilmek için, kendi Google Cloud Projenizden indireceğiniz credentials.json dosyasını uygulamanın ana dizinine yerleştirmeniz gerekmektedir.

  1. Google Cloud Console'a gidin ve yeni bir proje oluşturun.
  2. Google Drive API'yi aratın ve projeniz için etkinleştirin.
  3. OAuth consent screen (OAuth onay ekranı) ayarlayın. Uygulama türünü External seçin. Test kullanıcıları kısmına kendi Gmail adresinizi ekleyin.
  4. Credentials (Kimlik Bilgileri) sekmesine tıklayın, Create Credentials > OAuth client ID seçeneğini seçin.
  5. Application type (Uygulama türü) olarak Desktop App (Masaüstü Uygulaması) seçin ve isim verin.
  6. Oluşturulan istemcinin sağ tarafındaki indirme ikonuna tıklayarak JSON dosyasını indirin.
  7. Dosya adını tam olarak credentials.json yapın ve c:\Users\Birin\Birin\AntiGravity\ klasörünün içine yerleştirin.
  8. Bu işlemleri yaptıktan sonra sayfayı yenileyip "Hesabı Bağla" butonuna basarak yetkilendirmeyi tamamlayabilirsiniz.
